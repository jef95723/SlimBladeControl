# SlimBlade Control v0.6.1

By Jeffrey Liu. First public release for the wired Kensington SlimBlade (USB 047d:2041).

- Configure all four buttons and all six two-button combinations, including both diagonals.
- Record custom keyboard shortcuts or choose modifiers and a key directly, such as Option–Space.
- Open or focus an application from a button or pair.
- Adjust pointer speed, twist scrolling up to 20×, and combination timing with sliders or numeric fields.
- Run as a menu bar app, hidden from the Dock by default. Both icons have visibility options.
- Find author and version information on the new About page.

Closing settings keeps mappings running. Quit releases the trackball for basic native mouse use. Saved mappings from previous versions are preserved.

## Download and setup

Download **SlimBlade-Control-0.6.1-macOS-arm64.zip**, extract it, and move **SlimBlade Control.app** to Applications. This binary is for Apple Silicon; macOS 12+ is the build target, with testing performed on macOS 26.6.2.

The app is ad-hoc signed and **not notarized**. Accessibility and Input Monitoring are required; updating a locally signed build can require removing and re-adding those entries. Hiding the Dock icon needs no additional permission. There is no background helper, login item, updater, or telemetry.

Kensington’s driver must release the trackball. After disabling its trackball driver, reconnect USB once so macOS restores native mouse service. See the README for detailed setup and limitations. SlimBlade Pro and other device IDs are not supported.

## Validation

Seven Rust tests, native regression tests, and 640,000 randomized C/Rust transitions across all 64 pair configurations pass. UI checks cover shortcut recording, application selection, all six pair cards, the About page, Dock visibility, window reopening, and settings preservation. Tests intercept generated input and application launches; physical hardware acceptance coverage is documented in the README.
